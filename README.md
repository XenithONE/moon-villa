# 月の別荘 — Moon Villa

**公開ページ:** https://xenithone.github.io/moon-villa/

月面に建つ別荘の居間に座り、大きな窓越しに地球を眺めるノスタルジックな Web 3D 空間。
時間は早送りで流れ、地球は誕生（46 億年前）から遠い未来（50 億年後）まで姿を変えていく。
傍らのラジオで音楽を流しながら、隕石が地球に落ちる瞬間も見届ける。

## 操作

| 操作 | 内容 |
|---|---|
| ドラッグ／マウス移動 | 見回す |
| W A S D ／ 矢印 | 歩く（Shift で早歩き） |
| C | 座る／立つ（デイベッドに座って眺める） |
| スペース | 時間の再生／停止 |
| ← → | 時間を少し戻す／進める |
| 1〜4 | 再生速度（0.5× / 1× / 2× / 4×） |
| M | 隕石を落とす |
| R | ラジオを開く（3D のラジオをクリックしても開く） |
| F | 全画面 |

## 開発

```bash
npm install
npm run dev      # http://localhost:5174/moon-villa/
npm test         # タイムライン・年代パラメータのテスト
npm run build    # dist/ に出力
```

## 音楽を入れる

`public/music/` に音声ファイルを置き、`public/music/playlist.json` に追記する。詳細は `public/music/README.md`。

## 構成

- `src/time/` — 年代 ⇄ 正規化時間の写像、時代ごとの外観パラメータ、イベント（純粋関数・テスト付き）
- `src/scene/` — 別荘・月面・星空・地球シェーダ・隕石演出・ポスト処理
- `src/audio/` — ラジオ（プレイリスト、AM 風フィルタ、局間ノイズ、衝突音）
- `src/ui/` — 入場画面、年代表示、タイムライン、ラジオパネル
- `docs/superpowers/` — 設計書と実装計画

外部モデル・テクスチャは使わず、全てプロシージャル生成。three.js 0.185 (WebGL) + Vite 8。
